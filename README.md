# lifeKLINE

人生 K 线图 - 基于八字命理的人生运势量化系统

## 功能

- 单人 Life-Kline 分析
- Hepan 合盘分析
- 多维度（财富/生命/情感）分析
- 多周期（日K/月K/年K）视图
- 技术指标（MACD/KDJ/RSI/BOLL）展示

## 开发

```bash
pnpm install
pnpm dev
```

## 构建

```bash
pnpm build
```

## 测试

```bash
pnpm test:run
```
